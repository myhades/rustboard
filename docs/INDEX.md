# Rustboard documentation

Current sources of truth:

- [Architecture](ARCHITECTURE.md): responsibilities, tree, data flow and platform limits.
- [Protocol](PROTOCOL.md): current wire format and bounded file-transfer lifetime.
- [Installation](INSTALLATION.md): build, install, CLI, configuration and pairing.
- [Security](SECURITY.md): device credentials, peer trust and native IPC.
- [Development](DEVELOPMENT.md): tests, standalone tools and contribution workflow.

`archive/` contains historical development/handoff reports, including AI instructions that are no longer current. `test-results/` preserves recorded measurements; old filenames are evidence, not compatibility modes. Do not execute archived signing/install commands. Current platform scripts live under `platforms/`.
